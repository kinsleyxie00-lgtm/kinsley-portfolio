# 彩色 Hero 与页面直切设计规格

## 项目目标

以用户提供的三张参考图为唯一视觉基准，继续重构 KINSLEY XIE Portfolio。

古树摄影作为全屏入口，并保留原始暖色。只有四株植物在初始状态呈灰白低饱和；鼠标悬停或键盘聚焦时，植物恢复自然绿色并产生克制的生长感。点击植物后立即进入对应内容页面。

进入内容页面后，顶部导航始终保留。About、Experience、Projects、Photography 之间直接切换，不刷新或改变网址。页面不会自动返回 Hero，但用户可以主动点击左侧 K.X 回到 Hero。

## 本阶段范围

本阶段完成：

1. 彩色摄影 Hero 与四株植物 hover 交互；

4. 顶部导航在四个内容页面之间直接切换；
5. 四个页面底部共用的 Contact 收尾模块。

必须保留：

- 现有 KSX 开屏动画；
- Kinsley 已有 About、Experience、Projects、Photography、Contact 内容；

- 现有本地图片与素材，以及为完善 VIS 排版而新增的匹配图片；

允许新增符合现有 VIS 的植物、自然材质、静物或编辑摄影图片，但必须服务于版式、色调统一且记录来源。不得另建第二套首页或导航，也不创建独立页面路由。

## Hero 设计

KSX 开屏播放结束后，显示 `/public/images/tree-aquatic-archive-v3.png`。

Hero 要求：

- 古树、树皮、水面、倒影、墙面和苔藓保留原始暖色；
- 只有四株入口植物呈灰白低饱和；
- 左上保留小型 K.X 品牌入口；
- 顶部显示 K.X 与四项极简内容导航；
- 左侧留白区域可放一句简短衬线体表达；
- 植物旁使用克制的小标签标明栏目；
- 可在角落保留 `Observe / Curate / Create` 等极短辅助文字。

图片必须是视觉主体。文字不能形成传统作品集的大段介绍，也不能覆盖植物。

鼠标移动只产生非常轻微的摄影视差；触屏设备和减少动态效果模式保持静态。

## 四株植物入口

四株植物按参考图绑定：

| 图片位置 | 对应页面 |
| --- | --- |
| 树干顶部 | About |
| 中央偏左树干 | Experience |
| 右侧树枝 | Projects |

热点必须绑定到真实植物位置，不能使用任意屏幕区域。桌面端和移动端可以分别校准坐标。

每个入口使用语义化按钮，并提供至少 44 像素的可点击区域。键盘与触屏均可操作。

## 植物初始状态与 Hover

树木照片整体保持彩色，每株植物单独覆盖局部灰度效果。

鼠标悬停或键盘聚焦时：

1. 当前植物从灰白恢复为原图绿色；
2. 绿色从植物生长点自然扩散；
3. 叶片产生极小幅度的展开、放大和亮度变化；
4. 植物旁的栏目标签提高对比度。

鼠标离开后恢复灰白。这个过程不需要点击，也不保存成长状态。

不得使用粒子、光晕、孢子、发光门户、游戏状态文字或幻想效果。

触屏点击应直接进入页面，不额外要求第二次点击。

## 点击与转场

点击植物后立即开始页面转场，不等待 hover 动画播放完毕。

Hero 退出可使用：

- 不超过几个百分点的图片缩放；
- 短暂的模糊和透明度变化；
- 内容页面从下方或侧面柔和揭示。

转场必须克制、平滑，不改变 URL、路由或 hash，也不刷新页面。

## 页面状态逻辑

网站只维护一个当前视图：

```text
hero | about | experience | projects | photography
```

Hero 在开屏之后首先出现；用户也可以在任意内容页面主动点击 K.X 返回 Hero。

进入任意内容页面后：

- 不显示额外的“返回 Hero”按钮；
- K.X 是唯一返回 Hero 的入口；
- 页面不会因为转场、滚动、Escape 或内容关闭而自动返回 Hero；
- 点击其他顶部导航，直接切换到对应页面；
- 切换过程中不能短暂露出 Hero。

Projects 项目详情和 Photography 灯箱仍可使用 Escape 关闭，但只能返回各自的 Projects 或 Photography 页面。

## 顶部导航

顶部导航固定包含：

```text
K.X / About / Experience / Projects / Photography
```

Hero 和所有内容页面共用同一个导航组件。点击 K.X 主动进入 Hero；点击四个栏目直接打开或切换内容页面。

当前页面使用细线或轻微颜色变化表示激活状态。移动端可以收为极简菜单，但不能创建另一套导航逻辑。

## 编辑式页面框架

四个内容页面共用统一视觉语言，但不能看起来像完全相同的模板。

About、Experience、Projects、Photography 都可以借鉴 FMRG Work 的内容组织与动效节奏。每个页面都应根据自身内容组合以下元素：

- 清晰的大标题；
- 一句简洁的栏目定位；
- 由横图、竖图和局部细节组成的图片组；
- 描述主题、能力或角色的标签；
- 可进入更深内容的详情入口；
- 图片与文字之间克制、连续的动态揭示。

四个页面共享这套“展览目录”语法，但必须使用不同的网格比例、图片节奏和详情结构。不得把同一布局只替换标题后重复四次。

共同原则：

- 暖白、暖灰或矿物色背景；
- 小型栏目编号和辅助信息；
- 大号衬线标题；
- 优先使用现有图片，并允许补充符合 VIS 的图片完善构图；
- 图片比例受控，采用不对称编辑网格；
- 文字分为故事、过程、结果等短段落；
- 大量留白，避免卡片和普通简历结构。

内容较长时允许当前页面内部纵向阅读，但首页不再把所有栏目连续向下排列。

### About

使用简短个人故事配合人像、植物或自然材质图片组。标题下使用一句个人定位；技能、工具与工作方法作为标签。详情入口可展开个人实践、能力结构或简历信息，但不做成简历卡片。

### Experience

采用有编号的编辑式经历时间线，并为重要经历配置图片组、角色标签和详情入口。每段经历展示背景、过程、个人贡献与结果，避免企业招聘网站式表格。

### Projects

参考用户提供的 Projects 构图，用现有及新增 VIS 图片组成不对称图片网格。每个项目包含标题、定位句、类别与角色标签、图片组和详情入口，并继续提供故事、过程和结果详情。

### Photography

采用展览墙或接触印样式网格。页面提供标题、影像定位、主题标签和系列入口；每个系列可使用不同比例图片组并进入灯箱详情。保留键盘左右切换。

### 共用 Contact 收尾

About、Experience、Projects、Photography 页面底部都保留同一个 Contact 收尾模块，不再设置独立 Contact 页面或顶部导航项。

Contact 收尾参考 FMRG Work 页面尾部的信息密度：使用清晰的分隔线、简短合作邀请、邮箱、电话、位置、简历下载和必要的版权信息。模块应像展览目录的封底，而不是大型 CTA 卡片。

每个页面可以根据背景色自动切换 Contact 的明暗配色，但信息、结构和交互保持一致。

### 四个页面的 FMRG Work 参考

About、Experience、Projects、Photography 都借鉴 FMRG Work 的内容节奏：标题与定位先建立主题，再通过不同比例图片组、分类标签和详情入口形成连续浏览体验。只借鉴结构、信息层级和动态节奏，不复制其图片、文字、品牌或项目设计。

## 动效原则

使用 GSAP、Framer Motion 与 CSS 完成：

- 植物 hover 灰白转绿；
- 非常轻微的图片视差；
- 页面间淡入、模糊与裁切揭示；
- 标题、辅助信息和图片的轻微错峰出现；
- 图片组进入视口时使用遮罩揭示、轻微缩放或透明度过渡；
- hover 项目或栏目时，标题、标签和图片之间产生克制的联动；
- 详情入口使用细线、箭头或文字位移反馈，不使用大型按钮；
- 页面切换延续 FMRG Work 的连续编辑感，但不复制具体动画参数；
- 内容区域平滑滚动。

避免夸张惯性、强烈镜头运动、弹跳、游戏感和持续环境动画。

减少动态效果模式下取消视差、模糊和错峰，只保留接近即时的透明度切换。

## 响应式

桌面端以宽幅参考图为主。移动端使用独立图片裁切和热点坐标。

如果竖屏无法同时展示四株植物，应优先保留尽可能多的真实植物，并保证顶部导航始终能够进入全部页面，不允许通过新增或伪造图片解决。

内容网格在移动端应转换为有节奏的编辑序列，而不是普通卡片纵向堆叠。所有按钮必须满足触屏尺寸和安全区要求。

## 异常与边界情况

- 局部植物灰度遮罩失败时，入口按钮仍可正常点击；
- 快速连续点击导航时，只展示最后选择的页面，不能重叠多个页面；
- KSX 开屏结束后始终先显示 Hero；
- 项目详情和摄影灯箱关闭后返回其父页面，而非 Hero；
- 植物 hover 是临时状态，不再需要 sessionStorage。

## 验收标准

- Hero 的色调、文字、植物标签和留白与三张参考图一致；
- 树干、水面、空间与倒影保持原始彩色；
- 只有四株植物初始灰白；
- hover 或键盘聚焦时植物恢复绿色并产生克制生长感；
- 点击植物立即打开正确页面；
- 内容页面没有返回 Hero 的按钮；
- 四个栏目可通过顶部导航直接切换；
- 只有点击 K.X 才主动进入 Hero，其他操作不会自动返回 Hero；
- 切换时不闪现 Hero，不刷新，不改变 URL；
- 四个栏目使用统一编辑框架，并可使用符合 VIS 的新增图片；
- 四个栏目均包含标题、定位、图片组、标签、详情入口及相应的克制动效；
- 四个栏目页面底部均显示共用 Contact 收尾；
- 项目详情和摄影灯箱继续正常工作；
- 桌面端、移动端、键盘、触屏和减少动态效果模式均可使用；
- `pnpm build` 通过；
- 仅保留本地预览，不部署。
