# Firefly 案例海报滚动弹层设计

## 目标

保留 Firefly Big Day 原始长海报的完整视觉，不重新拆分或改写内容。弹层改为适合连续阅读的纵向滚动布局，避免将整张海报压缩进单个视口导致文字过小。

## 展示方式

- 弹层覆盖当前页面，背景使用深色半透明遮罩与 `backdrop-filter` 磨砂，页面轮廓仍可辨认。
- 弹层自身承担纵向滚动；打开时从顶部开始，海报从上向下自然阅读。
- 海报在弹层中水平居中，桌面端按接近原始宽度展示，最大宽度为原图有效宽度 `852px`。
- 浏览器只允许按比例缩小，不允许超过原图有效尺寸放大；使用现有 PNG，不重新编码。
- 海报使用克制的圆角、边框与投影，模拟一张悬浮于页面上方的实体印刷海报。
- 顶部、底部和两侧保留安全留白，滚动至海报末尾时不会紧贴视口边缘。
- 手机端按视口安全宽度缩小海报，不产生横向滚动，并保持完整比例。

## 关闭交互

- 海报顶部可见时，由覆盖在原图右上角“关闭 ×”区域的透明按钮关闭弹层，不重复绘制关闭文字。
- 增加一个固定在视口右上角的纯图标关闭按钮，使用户滚动到海报中后段时仍可随时退出；该按钮不使用“关闭 ×”文字。
- 点击海报外的磨砂背景或按 `Escape` 均可关闭。
- 点击海报内容不会误触关闭。
- 弹层打开后焦点进入关闭控件，关闭后返回原 `OPEN CASE` 按钮。
- 弹层打开时锁定底层页面滚动，仅滚动案例弹层；每次重新打开都回到海报顶部。

## 响应式与可访问性

- 桌面端优先保证海报接近自然尺寸，使正文可读。
- 平板和手机端使用视口安全宽度，保持原始宽高比与完整内容。
- 两个关闭控件均提供无障碍名称和清晰的键盘焦点状态。
- 焦点限制在弹层中，支持键盘关闭并在退出后恢复原焦点。
- 不支持 `backdrop-filter` 的浏览器使用更深的纯半透明背景作为降级方案。

## 平整版海报素材

- 原始 `firefly-big-day-case.png` 中已经烘焙的纸面起伏与照片褶皱通过图像编辑处理，不使用 CSS 纹理抵消。
- 修图只拉平白色纸面和海报内的照片区域，并校正照片边缘，使横竖线更平直。
- 所有中文与英文文字、数字、车型、图片主体、版式位置、比例和配色均为不可变内容。
- 新素材以 `firefly-big-day-case-flat-v2.png` 保存，先与原图并存，不直接覆盖原文件。
- 新图生成后先检查文字准确性、布局一致性和图片主体完整性；未经用户确认，不切换网站引用。

## 验证

- 桌面端海报以可读宽度纵向滚动，且不超过 `852px` 放大。
- 手机端无横向滚动、无图片拉伸，完整内容可通过纵向滚动查看。
- 每次打开弹层均位于海报顶部。
- 海报原生关闭区域、悬浮关闭图标、背景与 `Escape` 均可关闭。
- 海报内部点击不会关闭，底层页面不会随弹层滚动。
- 海报表面保持平整，不叠加褶皱、噪点或做旧纹理。
- 平整版素材不得改变任何文案、数据、车型或版式结构。
- 原始海报文件保留，可随时回退。
- TypeScript 检查与生产构建通过。
